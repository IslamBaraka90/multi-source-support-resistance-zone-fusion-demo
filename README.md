# Multi-Source Support & Resistance Zone Fusion — demo app

A Node app that derives price levels from four independent sources, fuses them
into zones, and grades those zones — every number computed by the
[`fintech-algorithms`](https://www.npmjs.com/package/fintech-algorithms)
package rather than by this repository.

Scope and design are being written up in [`docs/SCOPE.md`](docs/SCOPE.md).
